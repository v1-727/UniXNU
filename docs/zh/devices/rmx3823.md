## 配置 {#configuration}

`implemented`

组件: `ArmDTPlatform`, `ArmCpu`, `SoftwareAES`, `XnuPrelink`, `DarwinBoot`.

### 硬件与依赖

- SM8550 kalama SoC support from UniXNU-sm8550-common, pinned at a9f45dc6.

### 配置

- board.toml sets soc\_source = sm8550, defconfig = rmx3823\_defconfig, device\_tree.source = device:dts/board.dts.
- dts/board.dts includes sm8550.dtsi and enables ufs, ufsphy, gpu, gmu and gpu\_smmu.
- configs/rmx3823\_defconfig carries only board deltas; the arch, soc and os fragments supply the base.

### 操作步骤

- Read the device over adb: getprop, /proc/cpuinfo, /sys/devices/soc0, /sys/firmware/devicetree/base/reserved-memory.
- Unpacked the stock dtbo.img \(big-endian dt\_table\_header, 4 entries\) and decompiled each DTB.
- Ran \`unixnu defconfig rmx3823\_defconfig --device .\` and inspected the merged out/rmx3823/&lt;profile&gt;/rmx3823/.config.

### 开发经验

- soc\_id 519 and machine KALAMA match sm8550.dtsi: 3x A510, 2x A710, 2x A715, 1x X3, and GPU Adreno740v2.
- Page size is 4096, which the Sm8550Platform kit requires; a 16K-page SM8550 would not work.
- dtbo entries 1 and 2 carry qcom,msm-id 0x207 \(519\) and are the board overlays; entries 0 and 3 carry 0x258/0x259 and do not match this device.
- soc:configs/sm8550.config sets CONFIG\_XNU\_NATIVE\_ADRENO=y while the device defconfig is applied last, so the two must be changed together with \[components\].
- unixnu builds only on macOS and Linux. On Windows, defconfig and status run, but the kernel, payload and firmware steps do not.
- .github/workflows/build.yml builds from this repository alone: it checks out upstream UniXNU/UniXNU as the engine, so the board needs no fork of the engine repository.

### 完成条件

- All source pins resolve; every selected component has a record; status shows the intended overrides and patch order.

### 当前范围

- The memory base and size, and the reserved-memory sizes, are provisional.
- Panel and touch are not identified; both need the vendor device tree from the firmware package.
- No uefi-rmx3823 firmware checkout exists yet.

### 下一步

- Push this repository and run the macOS workflow with steps = kernel to get the first kernel build.
